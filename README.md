# EduTwin AI Studio — Gemini Free Tier + Netlify

Существующий статический сайт сохранён. Новая страница `ai-studio.html` открывается из навигации и раздела материалов. Она содержит редактор презентаций и генератор одностраничных сайтов. В продукте нет заготовленных AI-ответов: без серверного ключа генерация сообщает, что Gemini не настроен.

## Установка и локальный запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm test
npm run build
```

Для настоящей генерации скопируйте `.env.example` в `.env`, заполните `GEMINI_API_KEY` новым ключом вашего бесплатного проекта Google AI Studio, затем запустите `npm run preview`. Откройте http://127.0.0.1:4173/ai-studio.html . `npm run dev` запускает Netlify Dev с тем же локальным сервером. Файл `.env` не входит в публичную сборку и должен оставаться вне Git.

Старый ключ, найденный в исходной интеграции chat, удалён из этой версии. Его необходимо отозвать в Google AI Studio. Не присылайте новый ключ в чат и не вставляйте его в HTML/JavaScript браузера.

## Деплой на Netlify

1. Распакуйте исходники из архива и загрузите их в свой Git-репозиторий, без `node_modules`, `.env`, `dist` и `.netlify`.
2. Подключите репозиторий в Netlify. Настройки уже заданы в `netlify.toml`: команда `npm run build`, publish `dist`, Functions `netlify/functions`, Node.js 22.
3. В Netlify Environment variables добавьте `GEMINI_API_KEY` со scope **Functions** и `GEMINI_MODEL=gemini-3.5-flash-lite`. Секрет нужен во время выполнения функций, а не в браузере. Затем сделайте новый deploy.
4. Проверьте `/ai-studio.html` и запросы `/api/ai/presentation`, `/api/ai/website`, `/api/chat`.
5. Для существующей почтовой функции добавьте её прежние `GMAIL_USER` и `GMAIL_PASS` отдельно, если она используется.

Обычный drag-and-drop папки `dist` публикует только статические файлы и не заменяет полноценный deploy функций. Используйте Git integration или Netlify CLI. Публично публикуется только allowlist статических файлов; серверный provider, тесты, зависимости и `.env` исключены.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `GEMINI_API_KEY` | Секретный ключ Free Tier проекта, только сервер |
| `GEMINI_MODEL` | По умолчанию `gemini-3.5-flash-lite` |
| `AI_REQUEST_TIMEOUT_MS` | Необязательно; по умолчанию 45000, максимум 50000 |
| `AI_MAX_OUTPUT_TOKENS` | Необязательно; по умолчанию и максимум 12000 |
| `GMAIL_USER`, `GMAIL_PASS` | Прежняя почтовая функция, без изменения её назначения |

Не используются OpenAI SDK, `OPENAI_API_KEY`, платный fallback, Redis или новые базы данных.

## Бесплатная квота

На предоставленных скриншотах Free Tier проекта для Gemini 3.5 Flash Lite видны примерно 15 запросов/минуту, 250 000 входных токенов/минуту и 500 запросов/день. Это подходит для небольших демонстраций двух функций. Каждый новый результат и каждое AI-изменение — отдельный запрос; существующий чат тоже расходует квоту проекта. Ручное редактирование, preview, восстановление версий и экспорт не обращаются к Gemini.

Доступность и квоты определяются вашим проектом и могут меняться. Проверяйте их в Google AI Studio. Используйте проект без подключённого billing: список моделей в коде сам по себе не может определить тариф вашего ключа. При 429 показывается сообщение об ограничении, текущий документ сохраняется; автоматического повторного запроса или платного переключения нет. Лимиты Netlify также самостоятельны; не включайте платный тариф ради этого MVP.

Официальные сведения: https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite , https://ai.google.dev/gemini-api/docs/pricing , https://ai.google.dev/gemini-api/docs/rate-limits , https://ai.google.dev/gemini-api/docs/generate-content/structured-output . Условия Free Tier, включая обработку отправленных данных Google, нужно учитывать при выборе учебных материалов.

## Архитектура

Browser → Netlify Function → общий `server/ai/provider.js` → Gemini → проверенный JSON → редактор.

Презентация: `{ title, language, audience, theme: { background, foreground, accent, font }, slides: [{ id, layout, title, body, bullets, notes }] }`. От 1 до 20 слайдов, пять композиций, редактирование текста и заметок, цветов и шрифта, добавление/удаление/перестановка, режим просмотра.

Сайт: строго `{ html, css, js }`. HTML — фрагмент body, CSS и vanilla JavaScript — отдельные строки. Редактор передаёт фактический текущий документ, включая ручные изменения, и последние шесть инструкций в следующий запрос.

Сервер проверяет размер и схему запросов и ответов, завершённость генерации, запрещённые HTML-теги и атрибуты. Provider отделён от HTTP-handler и prompts: другой AI API можно добавить позднее без замены редакторов. Сейчас разрешены только явно выбранные Gemini-модели; никаких автоматических альтернатив.

`server/ai` — provider, prompts, schemas, ошибки, guards; `netlify/functions/ai-*.js` — HTTP entry points; `assets/js/ai` — состояние, API-клиент, IndexedDB, редакторы, renderers и preview; `ai-studio.html` и `assets/css/ai-studio.css` — интерфейс.

## Preview и хранение

Новый iframe на каждое обновление, `sandbox="allow-scripts"` без `allow-same-origin`, `srcdoc`, дочерний CSP с nonce, запрет сети, внешних ресурсов, форм, навигации, iframe, workers. HTML проходит allowlist в браузере и на сервере. Код не вставляется в DOM основной страницы. Сообщения ошибок принимаются только от текущего iframe с соответствующим token и не запускают привилегированные операции.

Интерактивность внутри preview работает без внешних библиотек и API. Ошибки JavaScript показаны в интерфейсе; preview можно остановить. Такой iframe изолирует доступ к приложению, но не является отдельным процессом с гарантированным лимитом CPU: бесконечный цикл в произвольном JS может повесить вкладку. Скачанный HTML запускается отдельно вне sandbox.

Проекты и последние десять версий хранятся в IndexedDB текущего браузера. Есть перенос через JSON. Это не облачное хранилище и не синхронизация между устройствами. Если IndexedDB недоступен, показывается предупреждение и используется память до закрытия страницы. Отмена прекращает ожидание браузера; уже отправленный Gemini-запрос может всё равно израсходовать квоту.

MVP предназначен для контролируемой учебной демонстрации. Проверка Origin не заменяет авторизацию; публичный endpoint может исчерпать бесплатную квоту. Регистрация исходного сайта на localStorage не является серверной авторизацией.

## Добавленные пакеты

- `zod`: валидация JSON и схема для structured output Gemini.
- `parse5`: серверный разбор сгенерированного HTML по allowlist.
- `netlify-cli` (dev): локальный запуск и сборка Functions.
- `nodemailer` уже использовался и сохранён.

Gemini вызывается встроенным Node.js fetch, SDK не нужен. Browser QA использует Playwright отдельно от зависимостей приложения: установите его в своей среде либо задайте `PLAYWRIGHT_MODULE` с путём к установленному модулю, запустите локальный сервер и `node tests/browser-check.cjs`. Проверка использует тестовые ответы только внутри теста, а не в приложении.

## Проверки

`npm test` проверяет схемы, ошибки provider, отсутствие утечки ключа, сохранность текущих данных, историю и публичную сборку. Browser QA проверяет ручное редактирование, локальное сохранение после перезагрузки, просмотр слайдов, изменения существующего сайта, 429, восстановление, iframe isolation, блокировку ресурсов и адаптивность.
